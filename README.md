# Document AI OCR — Prototype

Image-to-text OCR using optional Tesseract, structured regex extraction and confidence flags.

**Status:** demo/prototype, not production ready. Uses public-free or synthetic sample content, never customer data.

## Run

```powershell
cd 02-document-ai-ocr
python -m pip install -r requirements.txt
python app.py
```

See `app.py` for implementation. A successful local run is needed before publishing.
